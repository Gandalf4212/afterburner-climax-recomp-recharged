After Burner Climax Recharged - native Windows build (ReXGlue static recompilation)
https://github.com/Gandalf4212/afterburner-climax-recomp-recharged

Game files are NOT included. You need your own After Burner Climax XBLA package
(World release, the Xbox 360 LIVE file C0B8A17E2A438BBE7D63573A04652DA71EE5DE5558).

Setup
  Put the package file (or the whole 58410A06 folder copied from the console) in this
  folder and run after_burner_climax.exe. The first start makes the "assets" folder from
  it; after that the package is not needed any more.
  If Windows says a DLL (e.g. VCRUNTIME140.dll) is missing, install the Microsoft Visual C++
  Redistributable 2015-2022 (x64): https://aka.ms/vs/17/release/vc_redist.x64.exe

F1 / Esc: settings. F11: fullscreen. Settings are saved in after_burner_climax.toml.
Controls: left stick / arrows = fly, A / Z = machine gun, B / X = missiles, LB RB / C V = Climax,
LT RT / A S = brake / accelerate, Start / Enter, Back / Backspace.

Based on darkuni's afterburner-climax-recomp. Unofficial fan project, not affiliated with or
endorsed by SEGA or Microsoft. The exe contains code machine-translated from the game's
executable; game data comes from your own package. Licenses: see licenses\.
